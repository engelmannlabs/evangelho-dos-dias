# Evangelho dos Dias

Feed RSS e publicação automatizada do podcast **Evangelho dos Dias** (Família Dias).

- Feed: https://engelmannlabs.github.io/evangelho-dos-dias/feed.xml
- Cada episódio é um release `ep-NNN` com o MP3 anexado.
- `transcribe.yml` transcreve o rascunho; `publish.yml` registra o episódio e gera o feed ao publicar; `spotify-link.yml` busca o link no Spotify a cada 30 min.
